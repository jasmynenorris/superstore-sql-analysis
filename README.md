# Superstore SQL Analysis

A SQL project built using a simulated retail Superstore dataset. This project demonstrates foundational SQL skills by querying business data to answer common retail and inventory questions using filtering, sorting, aggregation, and grouping techniques.

---

## Project Overview

This project explores a simulated retail Superstore database using SQL. The objective is to analyze product pricing, inventory levels, and product categories while practicing core SQL concepts commonly used by data analysts.

The queries demonstrate how SQL can be used to retrieve, summarize, and analyze business data to support decision-making.

---

## Dataset

This project uses a simulated Superstore inventory dataset containing information on:

- Product Name
- Product Category
- Product Price
- Inventory Quantity
- Customer Rating

The dataset was created for educational and portfolio purposes.

---

## Business Questions Answered

This project answers questions such as:

- Which products have the highest prices?
- What is the total value of products in the database?
- What is the average price of products within each category?
- Which products have the largest inventory levels?
- How does inventory vary across product categories?
